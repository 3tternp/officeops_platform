# Screenshots and Demo Assets

Place static images and GIFs used by `README.md` in this folder.

Recommended filenames:
- `overview.png` – dashboard overview
- `lms-actions.png` – LMS course detail with gated buttons
- `access-approval-iso.png` – Access approval modal showing ISO routing
- `demo.gif` – short product demo

Guidelines:
- Use PNG for UI screenshots; GIF for short demos.
- Keep images under 2MB each; GIF under 10MB.
- Prefer 1440×900 or 1280×800 resolution for clarity.

Example Markdown embeds:
- `![Overview](docs/assets/overview.png)`
- `![LMS Actions](docs/assets/lms-actions.png)`
- `![Access Approval ISO](docs/assets/access-approval-iso.png)`
- `![Demo](docs/assets/demo.gif)`
